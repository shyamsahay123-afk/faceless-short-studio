🛡️ Defensive Track - How to Stop It

  1. Recon Defense: Block /.git/, remove robots.txt sensitive, disable directory listing
  2. SQLi Defense: Use parameterized queries, not string concatenation
  3. IDOR Defense: Check ownership: if file.owner != current_user: deny
  4. XSS Defense: Escape output, use Content-Security-Policy, sanitize comments
  5. LFI Defense: Whitelist files, block ../, use basename()
  6. Command Injection: Never use user input in shell, use subprocess without shell=True
  7. Upload Defense: Check MIME type, rename files, store outside webroot
  8. IP Blocking: Implement in /defense - block attacker IPs, log attempts
