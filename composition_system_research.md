# COMPOSITION SYSTEM: HOW STICKERS / TEXT / GRAPHICS / CLIPS / SOUNDS / VISUALS ARE USED
Date: 2026-08-25
Sources: Opus 12.2M-clip B-roll study, CapCut VFX workflow guides, YouTubeSFX retention data, beat-sync editing guides, meme-sound research, kinetic typography studies (2025-26).

## THE 7-LAYER STACK (back to front) — every winning short is built from these
| Layer | Element | Rule |
|-------|---------|------|
| L1 | BACKGROUND | Dark grid/gradient, ALWAYS on, luminance floor (never 90%+ black) |
| L2 | B-ROLL (their HD clips) | 2-4s max per clip, 3 types mixed, hard cuts, zoom-punch on keywords |
| L3 | GRAPHICS (cards) | Mock UI / stat / before-after cards = the "information" layer |
| L4 | STICKERS | Arrows, checks, emoji bursts = supporting, max 1-2 on screen, "at the moment" |
| L5 | BEAT TEXT | 2-4 word script pops every 1-2s, pops ON the beat |
| L6 | HOOK TEXT | 3-line stack, top third, 0.0-0.7s, holds ~3s |
| L7 | CAPTIONS | word-by-word, bottom 18%, karaoke highlight, dark panel behind |
| L0 | AUDIO | VO loudest, music -22dB, SFX map (below) |

## TEXT — how it's used
- Hook text in first 0.5s is "critical" (CapCut workflow). 3-7 words.
- Types in order of importance: HOOK > BEATS (steps/stats/questions) > CTA outro > captions
- Overlays exist for: key stats, questions, step numbers, CTAs (12.2M-clip study)
- Animations: IN (pop/bounce with 1.05 overshoot, slide, typewriter), OUT (fade/slide/dissolve), LOOP (subtle bounce/wave for hooks)
- 3-second rule: every 3s do something new — cut, zoom, overlay, or move text
- Beat-sync: text appears ON beats, pulses on hi-hats
- Visual wave: 0-3s action, 3-6s reaction, 6-9s reflection (repeat)
- Hierarchy: one dominant (hook) + one support (beat) + micro labels; if all animate, nothing matters

## STICKERS — how they're used
- 6 real types: text stickers (animated type), shape stickers (arrows/circles/checks), emoji stickers (animated), character stickers (reactions/mascots), element stickers (frames/dividers), custom (uploads)
- Rule for growth/education content: "stickers as supporting elements (arrows, checkmarks)" — NEVER the star
- Rule for entertainment: "sticker at THE moment" + SFX behind it (punchline hit)
- Motion stickers/zoom: SPARINGLY, one per shot max
- In reference channels: curved arrow pointing at card (signature), red glowing YT logo, "10M views" stat sticker, shocked-man reaction sticker
- "Insta memes" = reaction GIF/sticker (shocked man, crying laugh, pointing) + meme card + optional meme audio; 1-2 per video for premium niches, more for comedy

## GRAPHICS (cards) — the information layer
- Mock UI cards (fake YouTube UI, list with redacted items), stat cards, before/after split panels (red vs green), progress bars, step counters
- Card = white/dark rounded rect, 2-4px border, 2-4° rotation, drop shadow, slide+pop in
- These are what make faceless videos look "produced": the video shows the thing it talks about

## VIDEO CLIPS (B-ROLL) — the 12.2M-clip study rules
- **3-5s MAX per clip** (social: 1-2s); longer = pulls focus from voice
- **Mix 3 types per minute**: LITERAL (matches the word) + METAPHORICAL (feels the idea) + ATMOSPHERIC (sets scene)
- **Same quality as A-roll** — mismatched quality is a TOP RETENTION KILLER (their HD clips = good, keep all same grade)
- **Vertical-native**: cropped 16:9 loses ~40% of visual info
- **J-cuts** (audio starts before picture) + **L-cuts** (audio continues after picture) to glue clips
- **Match-cuts** on shape/motion/color hide scene changes
- **Hard cuts > transitions**: transitions appear in only 2.4% of clips; cube/star transitions feel cheap; hard cut + whoosh feels premium
- **Front-load the most striking clip in first 1.2s**
- **Zoom punch** 10-15% on VO keywords (beat-zoom); zoom = primary motion, then add 1-2 complementary elements only
- **Speed ramp** 0.5x→1.5x→1x into the pivot; freeze-frame on key beats
- **Not enough footage?** speed ramps + zooms + overlay elements create change without new clips
- B-roll must be graded (mid-gray darkened) so clips share one look

## SOUNDS — the SFX timeline (measured from SFX-pack research)
- "Holy Grail" hook = visual + verbal + audio hook within first 1.5s
- **Hook hit at 0.4-1.0s**: sub-bass impact synced to hook visual/first word (algorithm tests retention in first 1.5s)
- **Whoosh on EVERY cut** (0.3-0.8s, mid-range so it cuts through VO): "cheapest way to make a low-effort edit feel intentional"
- **Pop** on every text-beat/sticker appearance
- **Riser 1-2s** into the pivot (~20s), sharp cut at peak + **impact hit** = standard pivot pattern
- Some creators stack 5-7 SFX in first 5 seconds (the retention window)
- Layer stacking: base cuts on KICK, overlay flashes on SNARE, text pulses on HI-HAT, color shifts on BASS
- Music at **-22dB** under VO; VO = loudest layer always
- Meme sounds: trending audio = free interest-targeting (5-10x reach); sync is the #1 skill — edit AROUND the audio; keep <5s for copyright safety
- 4 meme-sound types: trending / evergreen (sting, fail, victory) / niche community / sound-original

## 45s TIMELINE TEMPLATE (assembled)
| Time | Visual | Text | SFX |
|------|--------|------|-----|
| 0.0-0.7 | bg + striking clip + hook card | 3-line HOOK pops (staggered) | sub-bass HIT at 0.4s |
| 0.7-2s | clip A (literal) | benefit beat | whoosh on cut |
| 2-8s | clip B + stat card + arrow | step 1 pop | pop per beat, whoosh per cut |
| 8-12s | clip C + meme sticker (1x) | step 2 pop | riser starts ~11s |
| 12-20s | clip D + before/after card | step 3 pop | IMPACT at pivot ~13s |
| 20-35s | clips E-F + curiosity card (redacted) | warning/contrast beat | pop + whoosh |
| 35-42s | clip G + REVEAL (un-redact) | takeaway | music drop, VO ducks |
| 42-45s | bg + CTA card + loop line | "and that is because..." | hit + loop back to 0 |
Captions: word-by-word bottom 18% the ENTIRE time. Background: grid+glow the ENTIRE time.

## WHAT THE USER'S APP NEEDS (from this research)
1. Text customizer: edit each beat's words, color, size, position, animation (pop/slide/typewriter), timing — per 2s block
2. Sticker library (code-generated, no assets): arrow (curved, draw-in), check, stat card, mock-UI card, redacted list, shocked-reaction frame, glowing YT logo
3. Clip director: 2-4s auto-cut, zoom-punch on keywords, speed ramp at pivot, hard cut + whoosh, match-cut suggestions, front-load best clip
4. SFX engine: hit/whoosh/pop/riser/impact generated as WAVs + user folder for custom meme sounds (e.g. "fahhh")
5. Background always-on (grid/aurora/pinstripe/glow) with luminance floor
6. Grade pass on all clips (mid-gray darken + Shorts compression comp +15%)
7. Meme slots: 1-2 per video, user-choosable (reaction sticker + optional meme audio)
